# Phase 4: planned registry projection

T-0359 composes the canonical 24-capability registry, planned-only evaluation
gates, and ADR-001 release boundaries into a single immutable Python read model.
The projection is local, pure, and fail-closed: every capability remains planned
and external-model promotion remains blocked pending Legal approval.

This is not an API, model artifact, dataset, evaluation result, evidence store,
inference implementation, activation control, release workflow, or promotion
decision. Those capabilities remain excluded until ADR-001 has Legal approval
and the separately security-reviewed release workflow exists.
