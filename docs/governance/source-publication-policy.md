# Source-publication policy

- Decision date: 2026-08-12
- Owner: SyncCam AI repository owner
- Status: Temporary owner authorization; final legal and commercial review outstanding

## Current decision

The SyncamAi implementation repository may remain public while the application is being built. No open-source license is granted and no `LICENSE` file is added. The repository is therefore source-available for viewing only under the default copyright position; it must not be described as open source.

The owner currently plans to make the repository private after the application build is complete. That later visibility change cannot retract source already downloaded or cloned. GitHub also documents that existing public forks remain public and are detached when an upstream public repository becomes private.

## Publication controls

Public commits must never contain secrets, credentials, customer information, footage, evidence, biometric data, model weights, proprietary datasets, private infrastructure identifiers, or production configuration. Secret, dependency, license, contract, and vulnerability checks remain merge gates.

No contributor may add an open-source license, publish a package, release model artifacts, or change repository visibility without a new owner decision. Legal review of the final licensing and visibility posture remains required before GA.
